# The Sorting Game

A puzzle game: sort the items on the board into their categories, two at a time.

## Credit

* **Thomas Colthurst** created the [original](https://thomaswc.com/2025.html)
* **Victoria Roberts** adapted [the version](https://victoria.danclan.com/the-sorting-game.html) this one is copied from
* **Klaus Hilgenfelder** made this version with new categories, play it [here](https://wollmilchmedien.com/sortinggame)

## Notes

The categories are all new: derived from [Wiktionary](https://www.wiktionary.org), extracted by [kaikki.org](https://kaikki.org/dictionary/), parsed and curated by Claude, in `en.js` and `de.js`.
